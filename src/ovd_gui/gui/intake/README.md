# intake

## Overview

Widgets through which images enter the application by drag and drop; the drop itself is handled by `MainWindow`.

## Components

| Component | Description |
| --------- | ----------- |
| [drop_zone.py](./drop_zone.py) | `DropZone`: empty-state placeholder inviting drops, with open buttons. |
| [drop_overlay.py](./drop_overlay.py) | `DropOverlay`: translucent drag-over layer previewing what a drop adds. |
