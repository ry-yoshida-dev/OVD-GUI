# vocabulary

## Overview

Tests of `ovd_gui.vocabulary`.

## Components

| Component | Description |
| --------- | ----------- |
| [test_class_definition.py](./test_class_definition.py) | Parsing and writing `name: phrase, phrase` classes. |
| [test_class_vocabulary.py](./test_class_vocabulary.py) | Unique class names and phrases across classes. |
| [test_class_list_file.py](./test_class_list_file.py) | Reading and writing one-class-per-line class list files, plain names included. |
| [test_class_list_store.py](./test_class_list_store.py) | Remembering the last class list and named class sets in the data directory. |
